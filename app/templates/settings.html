View migration SQL

SQLite is no longer supported — the app reads and writes everything against the Supabase project above.

First-time setup checklist
  1. In Supabase, open the SQL editor and click View migration SQL from this app. Paste it into the editor and click Run — it creates the tables.
  2. Open Supabase → Settings → Database → Database password. Click Reset password if you don't remember it.
  3. Paste it above and hit Save & switch to Supabase. The app reloads its connection on the spot.
Advanced: custom connection URL

Use this if your network is IPv4-only (the direct db.<ref>.supabase.co:5432 connection is IPv6-only since 2024). Grab the Connection pooling URL from Supabase → Settings → Database (looks like aws-0-…pooler.supabase.com:6543) and paste it here. Leave blank to auto-derive from the project URL + password.

How this works

  1. Lead discovery (Google Maps + Bing Local + OpenStreetMap) does not need an API key.
  2. The Gemini key is only for the optional AI features: research, lead scoring, email/DM/call-script generation.
  3. Without Supabase the app stores everything in a local SQLite file under your home directory.
  4. With Supabase configured, every lead/outreach record syncs to your cloud project — install Lumora on a new machine and pick up where you left off.
